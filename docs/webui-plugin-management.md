# 插件管理、规则与沙盒使用

## 选择机器人并管理插件

从原有 MDUI 2 导航进入“插件”（`/#/plugins`）。页面从 `/api/bots` 读取真实机器人；没有机器人时只展示编译目录，配置和启停不可操作。独立调试标识仅在沙盒中使用，不能用于正式配置。

使用搜索和状态筛选找到插件，选择后查看当前 Bot 的详情。以下状态含义不同：

| 状态 | 含义 |
| --- | --- |
| 已编译注册 | 插件已包含在当前二进制中 |
| 生产配置已启用 | 该 Bot 的持久启用设置 |
| 选择策略允许 | Bot 的插件列表为空（允许所有），或包含该插件 ID |
| 插件实例已启动 | 当前 Native 实例已初始化并订阅；不代表 Bot 已连接 QQ |
| 实例状态 | 正常、异常、未加载；异常实例可保留活动状态，后续事件仍可恢复 |
| Bot 连接 | 机器人核心是否运行；与插件实例生命周期独立 |

被选择策略排除的插件仍可提前配置，但不能通过管理接口启用或重启。请在原有机器人管理配置中允许它。启用、禁用和重启只操作当前 Bot 的插件实例。

## 表单配置与保存

基础字段根据 Schema 自动呈现：字符串、布尔值、整数/数值、枚举、对象分组和可编辑数组。显示字段名称、必填状态、描述和默认值。可选字段可用“设置此字段”控制是否提交；未设置且有默认值时，后端会补默认值。

“高级 JSON 编辑”与表单共用一份草稿。切换模式保留修改，JSON 或数值无效时要求先修正。未知字段、null、超出表单容量或不支持的结构自动保留在 JSON 模式，不能静默删除。表单最多展开 8 层、100 个数组项目及约 500 个结构节点，较大配置继续用 JSON；最终仍由后端 Schema 校验。

“保存并应用配置”先验证和持久化。若当前实例需要新配置，会重新创建**当前插件实例**；未启用的插件在下次启用时读取。保存成功与重启失败分开显示，失败时可查看最近一次错误并修复。无变化不重复重启。离开页面、切换 Bot/插件、刷新或重置前会处理未保存修改。

“重启插件实例”不读取修改后的 Go 源码，不是代码热加载，也不会重启 ShizukuBot。源码变更仍须审核、生成 Registry、重新编译和部署。

## 沙盒调试

插件详情的“进入沙盒测试”会带入当前 Bot 和插件，也可从原导航进入 `/#/sandbox`。

- 真实 Bot 范围：读取已保存的插件配置及默认值，不使用未保存的表单草稿。
- 独立调试范围：自定义标识并使用 Schema 默认配置，不读取生产配置；显式选择某个已编译插件。
- 群聊/C2C：模拟对应规范消息，不启动机器人或发送真实 QQ 消息。
- 未启用插件：可显式选择独立测试，生产启用状态不改变。
- 每次发送创建新实例和临时状态；例如 counter 每次调试从 1 开始。

优先展示结构化 results：文本、Markdown、图片、富媒体、按钮与视频。Markdown/按钮显示源文本和数据，媒体显示信息及安全的 HTTP(S) 链接，不自动加载外部资源。它们是捕获结果，不表示已发送给 QQ。

执行状态区分已回复、完成无回复、无匹配处理器、失败、超时和取消；只有后端证实未匹配才显示“无匹配处理器”。旧后端缺少事实字段时会明确显示未报告匹配情况。耗时来自真实测量。清空会话不删除生产状态；页面最多保留最近 100 次调试记录。

沙盒是功能测试工具，不提供 OS 安全隔离。只运行已编译审核过的可信 Go 插件。

## 备份、错误与权限

在高级信息中导出配置/状态 JSON，备份包含插件自己的私有数据，应妥善保管。恢复文件最多 **4 MiB**，仅允许已编译插件且全部 Bot 仍存在；已有配置、实例或状态不覆盖，恢复后禁用。其他普通管理请求维持 2 MiB 限制。备份不是源码安装包。

详情展示最近一次真实实例错误，长错误可展开；加载、空数据、请求失败与权限不足分别显示。插件管理、恢复和沙盒 API 均沿用管理员认证及来源检查。普通用户不能通过更换前端参数获得管理权限。

社区页继续说明旧市场不兼容，不提供在线安装、远程编译或热加载。实际实现与验证见 [P2.1 报告](v2-p2-plugin-ui-report.md)。


## 规则与自动回复

导航新增独立“规则”页 `/#/rules`，不影响插件管理和原插件沙盒。选择真实 Bot 后可搜索规则、编辑触发词/来源/群范围/回复/优先级，保存后在线生效；新建默认禁用，建议先测试再主动启用。

规则测试与插件沙盒用途不同：规则页测试保存规则或显式草稿，显示排序、条件、停止原因和预期回复，不触发插件；`/#/sandbox` 继续独立测试 Go 插件、捕获富媒体与临时状态。草稿测试临时启用当前规则只是评估副本，不改变生产启用状态。

规则停止只影响后续规则，Go 插件仍可能回复。autoreply 示例保留，同一关键词可产生额外回复；页面提供提醒，不隐式改动插件配置。规则保存采用修订号，冲突及失败保留草稿，刷新前可复制必要内容。详细操作、API 与边界见 [规则指南](rules-guide.md)。
