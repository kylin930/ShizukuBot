# WebUI 文案与交互清单

基线：main `2f29b3c`（已合并 P2.3 / P2.3.1），2026-11-03。
修改前先保存真实浏览器截图，页面使用隔离的本地测试 Bot、规则和沙盒结果。

| 页面/位置 | 处理 | 保留的信息 |
| --- | --- | --- |
| 统计 | 保留数据、图表和概览；统一标签间距 | 实际数值，不做数字滚动或伪造数据 |
| 机器人启停 | 明确“已启动/已停止”或失败原因 | 平台返回错误不能报成功 |
| QQ 诊断 | 默认列接入方式、最近事件/回复/错误；其他内容移至“接入帮助” | 平台接受不等于客户端送达；缺少证据不推断成功 |
| 插件顶部 | 删除“管理已编译插件…重新构建和部署” | 源码更新说明移至重启帮助 |
| 插件运行区 | 缩短重启、配置未应用和策略排除说明 | 策略排除、异常、保存后重启失败仍清楚显示 |
| 插件保存/实例操作 | 简短结果由 Snackbar 提示；持续错误留在页内 | 保存成功但应用失败、刷新失败不能改报成功 |
| 插件备份 | 说明留在高级信息/恢复操作旁 | 私有数据、空范围恢复、禁用与不覆盖限制 |
| 规则顶部 | 两段机制说明移入“规则说明” | 匹配方式、优先级、范围、停止策略及插件重复回复 |
| 规则表单 | 精简标签与帮助，仍保留字节范围、空白和占位符约束 | 明确校验、版本冲突、草稿不丢失 |
| 规则删除 | 去掉内部快照描述 | 不可恢复、删除目标与确认 |
| 规则测试 | 简短模拟说明，细节可展开 | 不发送 QQ；草稿临时启用，未保存配置不被误认为生效 |
| 沙盒顶部 | “仅模拟执行，不会发送 QQ 消息。” | 所选 Bot / 默认配置差异放在范围帮助中 |
| 沙盒空态/结果 | “输入消息开始测试”；删除重复媒体机制说明 | 来源、回复类型、执行/错误结果仍可见 |
| 社区 | “旧版插件暂不支持。”和开发文档链接 | 编译部署说明放入帮助，不提供虚假安装入口 |
| 配置 | 缩短帮助；字段错误就近显示 | 凭证不回填、加载失败、未保存修改保护 |
| 关于 | 移除无法从 API 确认的前端固定版本，SDK 改为 botgo-plus | 源码 Core/WebUI 常量仍为 1.0.0，未新增版本 API或编造版本 |
| 登录 | 简短认证/网络错误，按钮显示登录中 | 失败后可重试；不回显密码 |
| 通用用词 | 用“机器人”“配置”“已保存”“已启用/禁用”“重启实例” | C2C、Webhook、JSON 等必要术语保留 |

反馈约定：Snackbar 用于短暂成功结果；字段错误放表单；Notice 用于加载、失败和
需要处理的持续状态；Dialog 用于删除与放弃修改。保留 MDUI 原生对话框和焦点管理。

动效清单：旧页面有 180ms 延迟渲染和 500ms 退出过渡；列表选中无自定义局部过渡；
卡片/App Bar/Rail/Drawer 整体 opacity 影响前景；部分 MDUI RGB 通道变量被当成完整颜色。
新增 250ms 页面进入、150ms 局部进入、列表选中和轻微按钮按压反馈；保留 MDUI 原生导航/对话框动效。
减少动态效果时关闭上述装饰动画，状态与焦点仍保持清晰。
