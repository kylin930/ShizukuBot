# WebUI 设置

从程序运行目录启动，浏览器进入对应端口。首次管理员密码在 `data/.admin-initial-password`，登录后可在用户页修改。

## 统计数据

配置 → 统计数据可选择保留期和每天清理时间，默认 90 天、Asia/Shanghai 03:00。
保存后生效，不重启机器人。“立即清理过期数据”采用已保存的设置，不清空全部统计。
缩短保留期并清理后，延长保留期不能恢复被删记录。
用户、群和收发数量均为保留期内数据；总体用户/群按各机器人分别去重后相加。
统计页可查看最近 7/30/90 天历史，范围会受保留期限制。数据库状态和最近错误可在设置中查看。
详细口径、备份和异常处理见 [统计存储](statistics-storage.md)。

## 内置指令

配置 → 内置指令可分别启用 `/help`、`/status`，保存后对所有机器人立即生效，重启后保留。
关闭内置指令后，规则和 Go 插件可处理同名消息；帮助列表仅列出启用的内置指令，调用前缀沿用各 Bot 的配置。
`#shizuku` 始终启用，可关闭“在 /help 指令列表中显示 #shizuku”。该选项控制 `{指令列表}` 自动生成的内容，不改写自定义模板中手动输入的文字。

新增配置字段位于原 `builtin_commands` 对象，旧配置缺少这些字段时均默认为 `true`，原有回复模板保留：

```json
{
  "help_enabled": true,
  "status_enabled": true,
  "show_shizuku_in_help": true
}
```

规则说明、重启说明、测试范围和接入帮助采用 MDUI 2 Tooltip，支持悬停、键盘聚焦、Esc 关闭和手机点按。
诊断记录、错误原文与高级信息/备份操作保留为功能内容；用户消息、日志和原始数据不做标点替换。

## 外观

- 背景：默认图片、HTTPS URL、安全的 `/static/` 图片路径或本地上传
- 上传：PNG/JPEG/WebP，最多 8 MiB，宽高均不超过 4096，且总像素不超过 1600 万
- 颜色：默认、紫色、蓝色、青绿色、粉色或 `#RRGGBB` 自定义主色
- 明暗：跟随系统、浅色、深色

修改后立即预览；点击“保存配置”才持久化到服务器。“取消预览”恢复已保存外观，离开未保存页面需确认。
加载失败的图片不会经普通表单保存；可选择“恢复默认背景”。原始 JSON 或直接 API 写入的远程地址后续若失效，页面会回退默认图，服务器配置保留，便于修改。
上传完成也需要保存配置。取消的临时上传会删除；切换已保存背景后旧上传文件会删除。
未保存上传最多保留 32 个文件；下次上传时回收超过 24 小时的未引用文件，避免遗留文件持续积累。

外观是服务器全局设置，不依赖 localStorage；新标签页、其他浏览器和登录页读取同一份公开外观数据。
其他已打开的浏览器刷新后使用新设置。公开数据仅含背景 URL、主色和明暗模式，不含凭证或完整配置。
后端不下载外部图片 URL，浏览器以无来源请求加载图片。

## 保存与冲突

配置表单与“保存原始配置”都携带读取时的版本标识。其他管理员已修改配置时，服务器拒绝旧版本覆盖；草稿保留，可复制内容后重新加载。
旧客户端省略版本标识仍兼容，建议新客户端始终发送 `revision`。
原始 JSON 支持新增的 `webui.appearance` 和 `statistics` 全局设置；机器人配置通过机器人页管理。
密码和 AppSecret 不回填；留空保留原值。配置保存采用临时文件和原子替换，失败不发布新的配置快照。
若配置文件已保存但运行中统计策略未能应用，会明确提示部分完成，请排除数据库错误后重新加载并重试。

配置示例（省略现有字段时请保留原 Bot 和指令模板）：

```json
{
  "webui": {
    "appearance": {
      "background": {"type": "default", "value": ""},
      "theme": {"mode": "auto", "primary_color": ""}
    }
  },
  "statistics": {
    "retention_days": 90,
    "cleanup_time": "03:00",
    "timezone": "Asia/Shanghai"
  }
}
```

该片段用于补充现有本机配置，不是可直接替换完整配置的文件。
旧配置缺少新字段会使用默认值，已有 Bot、Secret 和自定义指令模板保留。
